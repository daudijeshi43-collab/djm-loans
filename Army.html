⚙️ One-time Supabase Setup Required

To enable the real database & login, follow these steps:

  1. Go to supabase.com → create a free account
  2. Create a new project
  3. Go to Project Settings → API
  4. Copy your Project URL and anon public key
  5. Open this HTML file in a text editor
  6. Find YOUR_SUPABASE_URL and YOUR_SUPABASE_ANON_KEY and replace them
  7. Go to SQL Editor in Supabase and run the SQL below ↓

SQL to run in Supabase: 
CREATE TABLE loans (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id uuid REFERENCES auth.users(id) ON DELETE CASCADE,
  name text NOT NULL,
  phone text,
  amount numeric NOT NULL,
  date_lent date NOT NULL,
  date_due date NOT NULL,
  status text DEFAULT 'Pending',
  date_repaid date,
  amount_repaid numeric DEFAULT 0,
  notes text,
  created_at timestamptz DEFAULT now()
);

-- Enable Row Level Security
ALTER TABLE loans ENABLE ROW LEVEL SECURITY;

-- Each user only sees their own loans
CREATE POLICY "Users manage own loans"
  ON loans FOR ALL
  USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
